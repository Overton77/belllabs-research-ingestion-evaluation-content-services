# Agent-capability seed notes (FT-A6)

Seed bundles `mc.catalog.agent-capabilities@1.0.0` (common), `mc.app.biotech.agent-capabilities@1.0.0`
and `mc.app.ai-engineer.agent-capabilities@1.0.0` are generated by `generate_catalog_seeds.py` from
`agent_capabilities.py` and `tests/fixtures/mcp/<id>.tools.json`. They require migration 0025.

Only names are stored; values come from the lane's secret mechanism at run time.

## Tool lists

The `tools/list` fixtures are transcribed from `docs/specs/fast-track-2026-10/research/seed-capabilities-and-formats.md`
(`capture_method: transcribed`); no server was run in this wave. Input schemas are recorded as
`{"type": "object"}` until a live capture. Re-capture each server once with
`scripts/capture_mcp_tool_snapshot.py`, replace the fixture, regenerate the bundles (new seed
version if 1.0.0 was applied) and run `make seeds-validate`.

## Rejected candidates

| Candidate | Why |
| --- | --- |
| `sec-edgar-mcp` (PyPI 1.1.0) | AGPL-3.0 licence risk for a hosted Mission Control and unauthenticated HTTP transport |
| `pubmedmcp` (PyPI 0.1.4) | Stale (last upload 2025-09-02), no licence or author metadata |
| unscoped npm `pubmed-mcp-server` 1.0.0 | Not the cyanheads server; stale; name trap |
| `https://pubmed.caseyjhand.com/mcp` | Author-operated public endpoint; an untrusted third party for production. Cloud lanes need a self-hosted Streamable HTTP endpoint |
| Firecrawl key-in-URL form (`https://mcp.firecrawl.dev/<key>/v2/mcp`) | Undocumented legacy form; the README says never put a key in the URL |
| Tavily key-in-query form (`?tavilyApiKey=<key>`) | Puts the secret in URLs and logs; the Authorization header form is used instead |
| PyPI `biomcp` 0.0.1, npm `biomcp` | Unrelated projects (name traps); the real package is `biomcp-cli` |
