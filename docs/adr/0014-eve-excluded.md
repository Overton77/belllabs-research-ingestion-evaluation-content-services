# Eve is not a supported or planned execution lane

Earlier proposals included Eve as an execution lane. It is excluded from this architecture, not deferred, because it would require a second scheduler-like runtime; its fact sheet (`runtime-facts/EVE_FACTS.md`) is retained only until the cleanup review removes it.
