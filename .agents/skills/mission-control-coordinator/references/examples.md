# Examples

## Existing StageGraph

Goal: select schema context for an admitted research question.

Search Workflow Types, choose exact `schema-context-selection`, read its input contract, construct the manifest, resolve exact assets, prepare, launch, and return run/result URIs.

## Existing GoalDirected

Goal: bounded adaptive supporting-graph reconciliation.

Choose the existing supporting-graph Workflow Type and its approved GoalDirected implementation. Supply a concrete initial goal. Preparation freezes its digest; runtime derives protected scope and Goal Revision server-side.

## Missing capability

Goal requires a capability absent internally.

Report the internal gap, query the official MCP Registry or pinned `npx skills find`, record candidates, refuse direct attachment, and produce an inspection/promotion request.

## Two-provider browser research

Begin with natural-language intent. Retrieve the exact web-research Workflow Type, Firecrawl and Tavily search tools, their promoted search skills, `skill.agent-browser`, and the browser-capable Agent Profile. Freeze only the two search tool allowlists and explicit browser grants.
