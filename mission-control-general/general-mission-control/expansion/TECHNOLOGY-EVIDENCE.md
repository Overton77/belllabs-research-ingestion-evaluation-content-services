Read current [canonical specification](../SPECIFICATION.md), [system proposal](../MISSION_CONTROL_SYSTEM_PROPOSAL.md), [runtime contracts](../RUNTIME-CONTRACTS.md), [database](../DATABASE.md), workspace `Biotech/AGENTS.md`, relevant `.agents/skills/firecrawl/SKILL.md`, and `Biotech/biotech-meta/docs/BellLabs/vision-and-product-system.md`. The product vision requires decision/evidence navigation, continued lifecycle support and separation of public evidence from personal conclusions. A recursive package-manifest search within the Biotech workspace returned no declared `@mcp-ui/*`, `@modelcontextprotocol/ext-apps`, `@ai-sdk/*` or `ai` dependency. This is absence of discovered manifest evidence, not proof of absence across external AI Engineer repos or installed environments. No installed mobile host or Apps-compatible build was qualified. ## Decision/gap register and acceptance boundaries

| Gap | Classification | Evidence needed / stop condition |
| --- | --- | --- |
| Python MCP app resource registration and OAuth propagation | unqualified | Locked SDK/service fixture; authorized `tools/call`/`resources/read` scope parity. Stop if view receives reusable credentials or resolves cross-app data. |
| MCP-UI browser host | unqualified | Pinned wrapper/bridge bundles, hostile HTML/CSP/origin tests, fallback and version negotiation. Stop if SDK convenience requires weakening isolation. |
| iOS/Android Apps host bridge | unqualified | Real device/emulator shell builds and isolation/auth/deep-link/background tests. Native typed components are required fallback; WebView failure does not waive mobile release. |
| Generative component registry | proposed | Golden schema fixtures, unknown component/prop rejection, stale action tests and accessible fallback. Model prose never authorizes a mutation. |
| Durable WebSocket delivery | proposed | Duplicate/gap/retention/slow-reader/revocation and multi-process crash tests over app-local event ledger. No claim of exactly-once socket transport. |
| Review/notification revision races | proposed | Parallel decision fixture and target digest changes, timeout/resolution race, duplicate provider delivery and restart. Unknown delivery cannot become accepted decision. |
| Usage estimates and correction | proposed | Adapter normalized fixtures and current verified price-sheet provenance before dollar accounting. Missing bill remains unknown, never zero. |
| End-to-end mobile push provider | unqualified | Owning application config, permissions, test transport/provider receipt and reconnect inbox recovery. No provider account or paid service is provisioned here. |

These gaps block advertising/accepting the corresponding runtime capability, not authoring foundational contracts. All proof budgets start deterministic/local. Model-assisted interview evaluation is a later bounded proof allocation requiring explicit tokens/calls/concurrency and approved metered budget; no calendar timelines or unsupported dollar projections are prescribed.
